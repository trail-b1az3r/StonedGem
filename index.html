Rust · browser infrastructure · work in progress

A browser,
in pieces.

StonedGem is the Rust foundation being carved out of OyNIx. Browser services, extension plumbing, a scripting layer, and an engine experiment—kept separate so they can move without dragging the whole application with them.

What lives here

01 — COMPONENT MAP
01 / SERVICES

Browser primitives

URL resolution, profiles, encrypted vault, bookmarks, history and content filtering without being tied to a browser window.

02 / EXTENSIONS

Extension runtime

Chrome and Firefox extension support, OyNIx packages, TypeScript/TSX, network rules, widgets and panels.

03 / EXPERIMENT

Web engine

Servo behind project-owned types. The current engine work is a spike, not a claim of finished compatibility.

04 / LANGUAGE

Z#++

Embedded scripting, canvas APIs, shader kernels and sandboxing for extensions and UI work.

05 / THEMING

Hypertheme

Theme tokens and multiple authoring paths, with a node-based Theme Studio and sample theme.

06 / APP

OyNIx transition

Components are moved out in stages. The browser app remains the integration target while the seams are tested.

Keep the seams visible

02 — ARCHITECTURE
Current approach

Services first.
Window later.

StonedGem separates browser-facing services from the app shell. The engine experiment sits behind project types, while the window, extension runtime and theme layer stay independently testable. The goal is gradual migration, not a big rewrite day.
